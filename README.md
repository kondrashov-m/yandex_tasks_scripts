## kondrashov-m | Yandex.Tasks-scripts
Парсеры для автоматизации выполнения заданий в Яндекс.Заданиях. Разрабатывались под конкретные проекты Заданий (Толоки).
##
В октябре 2025 года я стал замечать, что на выполнение проектов в Яндекс.Заданиях уходит слишком много времени. Позднее я ушел с этого проекта, но перед этим решил разработать парочку скриптов, которые облегчат этот низкооплачиваемый труд. Встречайте! В этом репозитории собраны парсеры, которые помогают в выполнении проектов. Среди них: 
``` 
1. Парсер - рубрика сайта
2. Парсер - project_z
3. RAB Bot (бот для автоматической ловли и выполнения заданий)
```
Благодаря этим скриптам, я смог выйти на более менее стабильный доход. Страшно представить, что эти нейрослопные задания кто-то выполняет в серьёз. И так. Встречайте. Краткое описание каждого парсера.
##
## Парсер - рубрика сайта | Инструкция
```
Данный парсер писался индивидуально под проект "Сопоставление рубрики сайтов".  В нем было необходимо сопоставить рубрику сайта с карточкой. Для этого предоставлялось около 15-30 карточек. Было необходимо перейти по карточке, понять что это за сайт, выбрать нужную рубрику сайта из предложенного списка. Платили за данное задание около 4 рублей...4 рубля - вот он уровень Яндекса. Если все делать без скрипта, то времязатраты превышают 10 минут. 24 рубля в час - спасибо не надо.

Из-за чего появилась жесткая необходимость автоматизировать данные заказы. Скрипт парсит все ссылки с saved_resource.html и создает sites_content.txt.

Далее текст из sites_content.txt необходимо "скормить нейросети", которая самостоятельно определит рубрику сайта. Производительность увеличивается значительно. Благодаря скрипту решить одну таску можно за 2 минуты, вместо 10.
```
## Парсер - project_z
